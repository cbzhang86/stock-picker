# 自动化：T+1 结果回填 + 一行状态推送

## 执行要点（长期有效）

- `scripts/pick.py backfill` **不输出成功/失败/滞留三个数字**，只打印「自动回填 N 条…」。
  N 是 pending 池大小，不是成功数 → 必须靠前后快照 diff 才能拿到真实 N/M/K。
- 计量方式：跑回填前后各执行一次
  `python scripts/_backfill_measure.py before|after <json>`，再 diff `updated_at`/`status`。
  - N = `updated_at` 发生变化的行数
  - M = pending 中打印 `回填失败` 警告 或 `backfill_attempts` 递增的行数
  - K = pending 且 `date` 距今 > 20 个自然日
- **坑：`outcomes.updated_at` 是 SQLite `CURRENT_TIMESTAMP`（UTC）**，
  本地 18:09 CST 落库显示 10:09，别误判成"没写入"。
- pending 谓词 = `t1/t5/t20_close` 任一为 NULL 且 status != 'no_data'（见 feedback/tracker.py:348）。
  → pending 池**包含尚未到期的 T+5/T+20**，池子不小不代表失败。
- 判定"真失败"看缺失字段：只缺 t20 且交易日未满 20 天 = 正常未到期；
  t1 为 NULL 且已过 T+1 = 真失败。
